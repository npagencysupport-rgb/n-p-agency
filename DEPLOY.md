## Загрузка на Vercel

1. Загрузите **содержимое** этой папки в корень подключённого GitHub-репозитория, сохранив папки assets, api и en. Не загружайте ZIP вместо его содержимого.
2. В Vercel: Framework Preset → Other. Root Directory — папка с index.html и vercel.json. Build Command — без команды сборки. Output Directory — корень проекта (по умолчанию для статического проекта). Папка api должна входить в исходники проекта: Vercel создаст серверную функцию /api/contact.
3. Добавьте переменные в Settings → Environment Variables для Production:
   - TELEGRAM_BOT_TOKEN — новый токен, полученный через BotFather после перевыпуска опубликованного в чате токена.
   - TELEGRAM_CHAT_ID — 954569751.
4. Получатель должен открыть @testmenagerbot и нажать Start. Если токен принадлежит другому боту, Start нужен именно в нём.
5. Выполните новый Deploy/Redeploy после сохранения переменных. Переменные без нового деплоя не попадут в уже работающую функцию.
6. Отправьте реальную тестовую заявку, проверьте сообщение в личном Telegram-чате и подтверждение в форме. Не добавляйте токен в HTML, JS, GitHub или public environment variables.

На локальном предпросмотре отправка намеренно возвращает ошибку: настоящий токен не установлен. Серверная логика проверена с имитацией Telegram; реальная доставка не проверялась и не заявляется работающей до настройки выше.

Обработчик проверяет поля, источник запроса, ловушку для ботов и ограничивает всплески запросов в пределах экземпляра функции. Это не распределённая защита от спама: при открытом запуске настройте Vercel Firewall/rate limit для POST /api/contact. При ошибке доставки форма не очищается и не показывает ложное подтверждение.

## Домены и поиск

- vercel.json содержит 301 с www.np-agency.com.ua, np-agency-five.vercel.app и montell-site.vercel.app на основной домен с сохранением пути. Это работает только для доменов, обслуживаемых проектом с этим конфигом. Если старый адрес принадлежит другому Vercel-проекту, настройте редирект отдельно в том проекте.
- Проверка действующего SSL и редиректов извне в этой сессии была недоступна. После деплоя откройте основной домен и www по HTTPS, проверьте сертификат и конечный адрес. DNS-записи и сами доменные привязки этим архивом не меняются.
- Добавьте np-agency.com.ua в Google Search Console как Domain property. Полученный там TXT разместите у DNS-провайдера и отправьте https://np-agency.com.ua/sitemap.xml. Доступ к Google и код подтверждения не предоставлены; подключение не выполнено.
- Vercel Web Analytics: включите Analytics в том же проекте и проверьте первые просмотры. GA4 и Meta Pixel не добавлялись: нет Measurement ID/Pixel ID и согласованных настроек согласия. Не вставляйте фиктивные ID.
- Проверьте видео /demo_ukr.mp4 и /demo_eng.mp4. В коде используются относительные к корню пути нового домена.
- Старые social preview PNG сохранены для совместимости; метатеги ссылаются на новые preview-agency-uk-20261021.png и preview-agency-en-20261021.png.
